# אפליקציית ניהול בית משפחתי (Family Household Manager) 🏠

אפליקציית Full-stack מודרנית ורספונסיבית לניהול משק הבית, מותאמת במיוחד למובייל ולשימוש בזמן סידורים וקניות, עם תמיכה בריבוי משתמשים (חברי בית), מודול מטלות מתקדם עם סל מחזור, ומודול רשימות קניות ייעודי המחולק ל-4 תחומים עיקריים.

---

## 🌟 עיקרי המערכת ותכונות

### 1. ניהול משתמשים ומשק בית (Multi-user Support)
- **החלפת משתמשים נוחה בקליק:** מעבר מהיר בין בני הבית (הורים, שותפים, ילדים) ישירות מסרגל הניווט.
- **שיוך ומעקב:** כל מטלה וכל פריט קניות מתעדים מי יצר, למי שויך, ומי סימן שהושלם/נאסף לעגלה.
- **הוספת חברי בית חדשים:** התאמה אישית של שם, אווטאר (אימוג'י), צבע מזהה ותפקיד בבית.

---

### 2. מודול מטלות (Tasks Module)
- **סוגי מטלות:**
  - **⚡ חד-פעמית (One-time):** תיקונים, התקנות, סידורים מיוחדים.
  - **🔁 מחזורית (Recurring):** מטלות קבועות (יומי, שבועי, דו-שבועי, חודשי, מותאם אישית) כולל פירוט ימים (לדוגמה: "ימי ראשון בערב").
- **רמות דחיפות ברורות (Urgency Levels):**
  - 🔥 **דחוף (Urgent):** תג אדום בולט לביצוע מיידי.
  - ⏳ **בזמנך הפנוי (At your leisure):** תג זהוב/ענבר לביצוע במהלך השבוע כשמתפנה זמן.
  - 🛋️ **מתישהו (Sometime):** תג סגול/כחול לעדיפות נמוכה (לכשיתאפשר).
- **סל מחזור ושחזור מלא (Recycle Bin / Trash):**
  - מטלות שנמחקות אינן נהרסות מיד אלא מועברות ל-**סל מחזור (Recently Deleted)**.
  - **שחזור מלא (Restore):** כפתור שחזור בלחיצה אחת מחזיר את המטלה מיידית לרשימת המטלות הפעילות.
  - אפשרות למחיקה לצמיתות של מטלה בודדת או ריקון מלא של סל המחזור.
- **סינונים וחיפוש:** סינון מהיר לפי רמת דחיפות, סוג מטלה, סטטוס (לביצוע/הושלמו), שיוך אישי ("המטלות שלי"), וחיפוש טקסטואלי חופשי.
- **חגיגת סיום:** אנימציית קונפטי שמחה בעת השלמת מטלות!

---

### 3. מודול רשימות קניות (Shopping Lists Module)
מחולק ל-4 רשימות ייעודיות:

1. **🛒 סופר (Supermarket):**
   - **חלוקה למחלקות מסודרות:** ירקות ופירות, מאפים ולחמים, מוצרי חלב וביצים, בשר עוף ודגים, קפואים, מזווה ויבשים, משקאות, חטיפים ומתוקים, חומרי ניקוי וחד פעמי, וכללי.
   - **סדר מחלקות מותאם אישית (Custom Category Ordering):** מסך ייעודי לשינוי סדר הצגת המחלקות (בגרירה או בחצים למעלה/למטה), המאפשר להתאים את התצוגה בדיוק למסלול ההליכה בסניף הסופרמרקט המועדף עליכם (שופרסל, רמי לוי, אושר עד וכו').
   - **פאנל מועדפים מהיר (Favorites Staples):** מדף עליון לשליפה מהירה של מצרכי יסוד קבועים (חלב, ביצים, לחם, ירקות וכו') עם כפתור `[+]` בלחיצה אחת ישירות לסל הקניות!
   - **ניהול כמויות ויחידות:** שינוי כמות מהיר ב-`+` ו-`-` ישירות משורת המוצר, עם תמיכה ביחידות (יח', ק"ג, גרם, מארז, בקבוק, קופסה).
   - **מגירת "נאספו לעגלה" (In Cart):** הפרדה ברורה בין מוצרים שטרם נאספו למוצרים שנמצאים כבר בעגלה, כולל מונה התקדמות, כפתור "רוקן עגלה (סיום קנייה)" וכפתור איפוס לקנייה חוזרת.
2. **💊 מכבי / סופר-פארם (Pharmacy):**
   - רשימה ייעודית לבית מרקחת: תרופות, מרשמים מקוונים, ויטמינים, מוצרי תינוקות וטואלטיקה.
3. **📦 אלי אקספרס / מקס-סטוק (General / Cheap Store):**
   - מותאם במיוחד להזמנות אונליין, פריטי בית וסטוק: כולל שדה קישור אינטרנט לחיץ (פותח ישירות את דף המוצר ב-AliExpress) ושדה מחיר משוער בשקלים (₪).
4. **🏷️ אחר (Other):**
   - רשימת קניות גמישה לכל מטרה (טמבור, חנות חיות, כלי עבודה, הלבשה).

---

## 💻 ארכיטקטורה וטכנולוגיות

- **Backend:**
  - Node.js & Express.js
  - SQLite (דרך `better-sqlite3`) עם תמיכה ב-WAL mode ו-Foreign Keys
  - בסיס נתונים שמור מקומית ב-`server/data/household.db`
  - הגשת Static Assets מובנית עבור פריסה מלאה בשרת אחד
- **Frontend:**
  - React 18 + TypeScript + Vite
  - Tailwind CSS בעיצוב Mobile-First נקי ומלוטש
  - Lucide React Icons
  - תמיכה דו-לשונית מלאה: עברית (RTL) ואנגלית (LTR) בלחיצת כפתור
  - Canvas Confetti לאפקטי סיום

## 🚀 הוראות הרצה

### 1. התקנת תלויות (חד-פעמי):
```bash
npm run install:all
```

### 2. הפעלת סביבת פיתוח (שרת + ממשק משתמש במקביל):
```bash
npm run dev
```
האפליקציה תפעל בכתובת:
- **Client (Vite Dev Server):** `http://localhost:5173`
- **Server (Express API):** `http://localhost:3001`

### 3. הרצת גרסה מאוחדת (Unified Production Server):
ניתן לבנות את הקליינט ולהריץ את כל האפליקציה בפורט יחיד:
```bash
npm run build --prefix client
npm start --prefix server
```
האפליקציה המלאה תהיה זמינה ב: `http://localhost:3001`

### 4. הרצת בדיקות E2E אוטומטיות:
```bash
node test-e2e.js
```
בודק את כל תרחישי ה-API, המטלות, רמות הדחיפות, סל המחזור, השחזור, סדר המחלקות והמועדפים.
